### We are happy to announce the release of Persepolis Download Manager 5.1.0.

1. A new feature has been added to Persepolis. Persepolis can download files that have an unspecified size. Such as GitHub zip files and... .

2. The log window has been redesigned to make it easier to check error messages.

3. The installation prerequisites for Linux and BSD have changed. `libnotify`(`libnotify-bin`) and `pulseaudio` have been removed from the prerequisites and `python3-dasbus‍`(`python-dasbus‍`) has been added. Note that `yt-dlp`, `ffmpeg` and  `python3-dasbus‍` are optional prerequisites. Please check the installation dependencies on the [Persepolis Wiki](https://github.com/persepolisdm/persepolis/wiki/git-installation-instruction) for more information.

New version of [persepolis_lib](https://github.com/persepolisdm/persepolis_lib) has been released today.
